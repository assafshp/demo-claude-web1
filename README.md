# Web Calculator

A simple web calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations (add, subtract, multiply, divide)
- Clear, delete, and toggle sign functions
- Keyboard support
- Modern dark theme

## How to Run on Mac

### Option 1: Double-click to open

1. Open Finder
2. Navigate to the project folder
3. Double-click `index.html` - it will open in your default browser

### Option 2: Using Terminal

```bash
open index.html
```

### Option 3: Using a specific browser

```bash
# Open in Safari
open -a Safari index.html

# Open in Chrome
open -a "Google Chrome" index.html

# Open in Firefox
open -a Firefox index.html
```

### Option 4: Using a local server (for development)

```bash
# Using Python 3
python3 -m http.server 8000

# Then open http://localhost:8000 in your browser
```

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| 0-9 | Enter numbers |
| + - * / | Operations |
| Enter or = | Calculate result |
| Backspace | Delete last digit |
| Escape | Clear all |
| . | Decimal point |
